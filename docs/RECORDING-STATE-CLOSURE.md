# 录音操作与异常恢复闭环（1.0.49 / 50）

本轮优先录音触发、会话边界和文件恢复。双蓝牙输入选择问题暂停处理，不能把本轮改动描述成选麦修复。

## 已确认的原因

实机上报中，2026-11-18 10:14:31 UTC 的启动使用 `path=preflight`，网络预检到 10:14:45 才完成，耗时 13.619 秒。
手表命令有效期为八秒。正常使用路径保留了诊断开关，导致录音受网络延迟影响。
新版本移除界面上的切换入口，忽略旧偏好；ASK 采音不依赖登录、VPN 或 HTTP 请求。
发送仍需要登录和网络，失败时保留待发箱。

代码审查另发现并修正：系统动作没有核对会话 UUID；下一轮可能在旧音频尚未释放时开始；手机按钮绕过草稿 journal；失败启动留下空草稿；上传失败后缺少持续重试；录音目的地取自发送时的页面上下文。
这些是代码中确认的缺口，不代表每一条都已在用户手机复现。

手表实机还捕获到 `ENC_CHANGE` 先于 `CONNECT` 的顺序。旧处理在连接事件中无条件清空加密标志，导致手机已认证而手表拒绝手势。本轮在连接时读取 GAP 的实际加密状态，保留提前恢复的订阅；六种连接、加密、订阅顺序及旧连接事件均加入回归。

## 操作规则

| 手机真实状态 | BOOT 长按 | BOOT 短按 | PWR 长按 / 手机明确结束对话 |
| --- | --- | --- | --- |
| 待命，无草稿 | 新建一条录音，沿用尚未结束的逻辑对话 | 不开麦，返回无草稿 | 结束逻辑对话 |
| 正在启动 | 忙，不积压第二次开始 | 忙 | 取消启动，关闭本轮逻辑对话 |
| 正在录音 | 保存、发送一条，保留逻辑对话 | 封口暂停 | 保存、发送并结束逻辑对话 |
| 草稿暂停 | 发送现有草稿，保留逻辑对话 | 继续同一条录音 | 发送现有草稿并结束逻辑对话 |
| 正在合并保存 | 忙，不重复生成文件 | 忙 | 合并完成后结束逻辑对话 |
| 上传中或离线待发 | 可以录下一条 | 按录音状态处理 | 结束当前逻辑对话，旧待发项继续保留 |

手机的开始、暂停、继续、发送和结束入口与手表使用同一 journal 和命令处理器。
手机控制产生的内部命令不发给手表，避免命令序号误认。状态同步先于物理手势；上传进度不再使录音手势的状态版本无故失效。

## 异常行为

| 场景 | 处理与下一次操作 |
| --- | --- |
| 手机点击发送或停止录音 | 保存现有分段并发送；下次长按开始下一条，仍在原逻辑对话 |
| 手机系统通话界面明确挂断 | 有效段先保存，结束逻辑对话；下一条属于新对话 |
| 来电、系统停用音频、采音异常 | 保存有效段为暂停草稿，不自动发送、不自动恢复开麦；短按继续，长按发送 |
| 启动失败或取消，尚无有效样本 | 保留待核对的原文件，清理空草稿；下次长按可以重新开始 |
| 旧通话的延迟暂停、结束或音频回调 | 按会话 UUID、manager 身份和启动 generation 隔离，不影响新录音 |
| 上轮音频仍在释放 | 新一轮等待释放；命令过期返回失败，不迟到开麦 |
| App 被系统重启或手机重启 | 恢复已保存的草稿、分段顺序和待发项，不自动录音；暂停草稿短按继续、长按发送 |
| 强退或掉电时尚未封口的尾段 | 尝试校验；失败保留原文件供导出，不承诺未封口 AAC 一定能恢复 |
| 合并失败或磁盘不可写 | 原始段保留，明确失败；不能给发送成功反馈 |
| 合并时手机又挂断 / 手表 PWR | 合并不重复执行，成功后关闭逻辑对话；失败保留草稿并报告结束尚未完成 |
| 断网、VPN 关闭、登录失效 | 可以开始录音；发送进入本地待发箱，恢复后按同一逻辑对话顺序重试 |
| 网关回包丢失或网关重启 | 新接口持久去重，同一个消息 UUID 返回原回执，不再次发给 Agent |
| 旧网关上传结果未知 | 不自动重发；保留文件，核对回执或导出 |
| Agent 离线 | 手机保留待发项及已建立的会话映射，定时重试 |
| 用户删除了服务端会话 | 服务端返回已删除，不把旧消息默默送入新会话；手机保留文件供处理 |
| 手机切换项目或目标网关 | 已开始的逻辑对话保持原目标；目标不符时保留待发，不串发 |
| 手表重连、重复通知、丢确认 | 同命令 ID 重传，手机持久去重；下一次手势重新读取手机状态 |

- 直接采音不做网络预检、旧会话回调隔离、PWR 取消启动与保存后结束、空草稿恢复、目的地冻结：本轮补齐。
- 待发自动退避重试、登录恢复后续传、服务端回执核对、原始文件导出：本轮补齐。

## 验证边界

`tests/voice-lifecycle` 编译实际的 `VoiceConversationProbe.swift` 与 `WatchVoiceSession.swift`，只替换 Apple 系统 API 和媒体编解码边界。
测试覆盖断网未登录启动、旧动作、旧 manager 回调、手机结束后立即再开始、取消启动、权限拒绝、录音器失败、暂停继续、同/新逻辑对话、目的地变化、空草稿、外部停止、journal 重启、合并时结束、合并失败重试、离线文件保存。
这些检查不等于 iPhone 锁屏和系统调度实测；真实 AAC 合并/顺序仍由 Mac AVFoundation 测试检查。
更新后的前台、锁屏、多小时闲置、完整掉电、强退重开和断网补传仍需手机验收，不能提前标记全通过。
