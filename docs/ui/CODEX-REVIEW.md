初稿不能直接用于生产。Codex 集成时修正：

- 删除 Swift 预览状态工厂，默认状态改为未连接、电量未知，移除虚构默认百分比。

- 将长文案次级按钮改为纵向布局、允许换行和最小高度，减少窄屏及大字体截断。
- 去掉未测的 6 小时续航和 16ms 延迟，改正实际由手机采音的描述。HTML 标明静态示例，不能作为运行时或续航证据。
- `RelayWatchController` 由 Codex 实现，只读取既有状态，并调用已存在的 `phoneStart/phoneSend/phonePause/phoneEnd`。关闭新页面不会停止录音或断开设备。设置与诊断仍使用原页面。
- `WatchVoiceSession` 只新增五行只读状态投影；未改变命令处理、状态迁移、分段保存、会话边界、上传或重试实现。没有修改麦克风路由策略。

电量由独立模块读取，经过独立特征上报；首版每 60 秒读一次，手机重连读缓存。支持未知、过期和断连状态；电量记录 JSONL 可从新页面导出。只读 PMIC，不修改充电或供电配置。
