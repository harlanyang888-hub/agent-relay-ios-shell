# 1.0.51 (52) 界面修正约束

用户 2026-11-19 明确要求：

1. 原生壳右上角“穿戴设备”文字悬浮入口完全移除。在网页已有 `.panel-foot` 最右侧退出按钮的位置，显示无文字的手表图标；点它打开设备页，不退出登录，不遮挡新建对话。
2. 设备页、导航栏、电量历史页固定暗黑；不随手机浅色主题变白。
3. 产品展示名称统一为小写 `relay watch`，包括配对选择展示名与已绑定设备名称映射。BLE 广播过滤、UUID 和身份不变。
4. “电量记录”首先打开可视化曲线，可选时间范围、点选读数、区分充电/USB 与电池供电；无记录时明确提示。原始导出是曲线页的次级分享操作。

入口适配只在 iOS 原生壳可信主页面运行：隐藏原退出按钮，向同一 footer 插入图标按钮，不覆盖网页，不改 React 管理的按钮子节点。MutationObserver 支持页面重渲染，存在标记时不重复插入。非原生浏览器的网页没有修改。

浏览器行为检查已验证：原退出入口隐藏、图标无文字、重复挂载后无重复按钮、图标点击仅打开原生设备页、原新建对话按钮仍响应。完整 iOS 编译与既有录音回归由构建验证；最终外观仍需 iPhone 验收。

本轮没有修改录音引擎、系统通话、会话状态机、上传逻辑、电量采样或 ESP32 固件。
