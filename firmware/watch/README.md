# Agent Relay 手表固件

硬件：Waveshare ESP32-S3-Touch-AMOLED-2.06。框架：ESP-IDF 5.5.1，NimBLE。

固件只通过 BLE 操作手机端录音，不采集手表麦克风。当前为 v3 协议开发版，需要配套手机端协议处理，不能直接与已认可的 1.0.33 联调录音。

## 编译

在已安装 ESP-IDF 的终端运行：

```sh
idf.py set-target esp32s3
idf.py build
```

## 按键与反馈

- BOOT 短按：请求暂停或继续。
- BOOT 长按 1.2 秒：请求开始，或结束并发送本条录音。
- PWR 长按 1.2 秒：请求发送并结束会话。持续按住仍可能触发板载硬件关机。
- 只有手机返回执行成功才给成功震动；失败、未就绪和超时为三次短震。

GPIO0 为低有效 BOOT，GPIO10 为高有效 PWR，GPIO18 控制马达。马达驱动与按键需实机验收。初版不初始化显示屏、音频、Wi-Fi，不使用深度睡眠。

## 配对与恢复

服务沿用 A8D70200-6B44-4E93-A2D5-73F2A34B8180。201 特征提供按键通知及读取，202 接收手机写入的状态，203 提供设备标识。v3 数据头与旧协议不同，不把旧 START/STOP 当作新手势。

开启加密访问和 NVS 配对存储。开机与断线后广播，由手机中心发起连接。普通启动不清除 NVS；初始化失败时保留原数据并报错。首次烧录前备份原始 Flash，后续更新不能擦除 NVS。

连接、加密、订阅都完成后先请求手机快照，每次按键执行前再同步一次。一次只允许一个待确认操作；每秒重传同一个数据包，8 秒后停止，并重新同步。断线不积压按键。状态未知时不执行录音手势。

## v3 包格式

整数均为小端，包长 20 字节，适用于默认 ATT MTU。

请求：`AR`、版本 3、操作、启动随机数 uint32、序号 uint16、手机 epoch uint32、状态 revision uint16、手机时钟下的过期秒数 uint32。操作 0/1/2/3 对应同步、BOOT 长按、BOOT 短按、PWR 长按。同步的过期字段为 0；其他请求有效期 8 秒。

响应：`AR`、版本 3、结果、请求序号 uint16、手机 epoch uint32、revision uint16、手机 Unix 秒 uint32、采集状态 uint8、flags uint8、错误 uint8、保留 uint8。结果 0/1/2/4 对应快照、执行成功、失败、仅收到。采集状态 0/1/2/3/4 对应待命、启动、录音、暂停、收尾。

手机必须对启动随机数及序号去重，校验过期、epoch、revision，执行后保存结果再确认。仅收到不算成功。手机进程重启必须更换 epoch；revision 回绕前也必须更换 epoch。

```sh
gcc -std=c11 -Wall -Wextra -Werror main/watch_protocol.c tests/protocol_test.c -Imain -o /tmp/watch-test
/tmp/watch-test
```

覆盖未同步、忙时按键、错误长度、旧序号、接收与执行确认区分、重复成功、超时、迟到响应和断线。
